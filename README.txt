WordBullet Portable

How to run:
1. Double-click run_game.bat
2. Or launch WordBullet.exe directly

Folder contents:
- WordBullet.exe: main game executable
- assets: game art and data
- fonts: local font fallback
- sfml-*.dll: SFML runtime libraries
- msvcp/vcruntime DLLs: MSVC runtime for another PC

LAN notes:
- Let the host click "Create Room" first
- Let the other PC click "Join Room" to search on the LAN
- If Windows Firewall prompts, allow the app on private networks
